# Oyaaro Party

Fresh Flutter/Dart social voice-party application.

## Phase 1
- Flutter project foundation
- Oyaaro theme and navigation
- Home, Messages, Rooms and Profile screens
- GitHub Actions Android APK build

## Planned phases
- Authentication and profile API
- LiveKit voice rooms and speaker seats
- Chat, gifts, coins and wallet
- VIP, rankings, families and moderation
- PHP/MySQL backend (to be decided later)

Features are not marked complete until implemented and tested.
